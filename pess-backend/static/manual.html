📖 User System Manual

Welcome to the Parent Engagement Support System (PESS). This manual explains how students, parents, and admins can use the system effectively.

🔑 Login

  • Students: Use your serial number and password to access your dashboard.
  • Parents: Log in using your child’s serial number and password provided by the admin.
  • Admins: Use your admin credentials to access management tools.

📚 Virtual Library

  • Students can access Books, Packages, Past Papers, and Learning Links.
  • Parents can view resources linked to their child’s progress.
  • Admins can upload and manage resources for all users.

🔔 Notifications

  • Students and parents receive announcements targeted to their role.
  • Admins can add new notifications for users.

📊 Dashboards

  • Students: View attendance, performance, and fee balances.
  • Parents: Monitor student progress and receive updates.
  • Admins: Manage suspensions, uploads, and system content.

🔒 Password Recovery

If you forget your password, contact the system administrator. For security reasons, passwords are not reset automatically — the admin will apply multi‑factor verification questions (such as student serial number, date of birth, or parent contact details) before issuing a new password.

🛠 Tips

  • Always log out after use for security.
  • Use the “Remember Me” option for persistent login.
  • Check the manual regularly for updates.
