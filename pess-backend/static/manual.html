📖 User System Manual

Welcome to the Parent Engagement Support System (PESS). This manual explains how to use the system effectively.

🔑 Login

  • Students/Parents: Use your serial number and password.
  • Admins: Use your admin credentials to access management tools.
  • Visitors: Click “Continue as Visitor” for limited access.

📚 Virtual Library

  • Access Books, Packages, Past Papers, and Learning Links.
  • Admins can upload and manage resources.
  • Users can view and download available materials.

🔔 Notifications

  • Receive announcements targeted to your role (student, parent, admin).
  • Admins can add new notifications for users.

📊 Dashboards

  • Students: View attendance, performance, and fee balances.
  • Parents: Monitor student progress and receive updates.
  • Admins: Manage suspensions, uploads, and system content.

👥 Visitor Guide

Visitors can explore public resources and learn how to register. To unlock full features, create an account via the registration page.

🛠 Tips

  • Always log out after use for security.
  • Use the “Remember Me” option for persistent login.
  • Check the manual regularly for updates.
